MetroWerks runtime / MSL_C / MetroTRK headers, taken from the Pikmin 2 decomp
(https://github.com/projectPiki/pikmin2), which uses the same SDK version as Pokemon XD.
Only the MSL_C, Runtime.PPCEABI.H and TRK_MINNOW_DOLPHIN libraries add this folder to their
include path (see cflags_sdk_ref in configure.py).
