# Pokémon XD: Gale of Darkness — Decompilation

A matching decompilation of **Pokémon XD: Gale of Darkness** (GameCube, USA, `GXXE01`).

The goal is C/C++ source code that compiles, with the original Metrowerks CodeWarrior compiler, to a
byte-identical copy of the retail game executable (`main.dol`). Once the code is understood well enough, it
can serve as the basis for ports, mods and documentation of the game's systems.

This repository contains **no game assets, ROMs, ISOs or executables**. You need your own legally obtained
copy of the game to build it.

## Building

### Requirements

- Python 3.9+
- [Ninja](https://ninja-build.org/) 1.3+
- Windows, Linux or macOS (on non-Windows hosts the original compilers run through
  [wibo](https://github.com/decompals/wibo) or Wine; the build downloads what it needs)

### Steps

1. Clone the repository with its submodules:

   ```
   git clone --recursive <this repository>
   ```

2. Extract `sys/main.dol` from your copy of the game (USA, `GXXE01`) and place it at
   `orig/GXXE01/sys/main.dol`. Any GameCube disc extraction tool (e.g. Dolphin's "Extract System Data")
   works.

3. Configure and build:

   ```
   python configure.py
   ninja
   ```

   A successful build ends with `build/GXXE01/main.dol: OK`, meaning the rebuilt executable is identical
   to the original.

## Repository layout

| Path | Contents |
|---|---|
| `src/` | Decompiled C/C++ source, organised like the original project |
| `include/` | Headers (game, Dolphin SDK, MSL, HAL sysdolphin) |
| `config/GXXE01/` | Symbol map, file splits and build configuration for the USA version |
| `configure.py` | Lists every source file and whether it currently matches |
| `tools/` | Build tooling |
| `extern/` | Third-party sources (MusyX audio library) |

Files marked `MatchingFor("GXXE01")` in `configure.py` are complete and linked into the build; files marked
`NonMatching` are in progress (their status is noted at the top of each source file).

## Contributing

Pick a `NonMatching` file or an unwritten function from `build/GXXE01/report.json`, write C/C++ for it,
and compare the compiled object with the original using [objdiff](https://github.com/encounter/objdiff)
(`objdiff.json` is generated by `configure.py`). A function only counts once it matches byte for byte, and
`ninja` must still finish with `main.dol: OK`.
